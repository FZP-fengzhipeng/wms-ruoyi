# 茶文化首页设计说明

## 1. 设计目标

- 建立统一茶叶品牌视觉入口，替代原驾驶舱/大屏/蓝图三入口。
- 首页作为默认落地页，突出“茶文化 + 经营中台”的定位。
- 视觉风格偏国风与现代后台结合，保证长期可维护。

## 2. 视觉规范

- 主色：茶绿（深绿/青绿）  
- 辅色：宣纸米白、浅灰绿  
- 基调：留白、卡片化、信息层级清晰

## 3. 页面结构

1. Hero 区  
   - 茶叶品牌 Logo  
   - 系统名与一句话定位  
   - 茶文化短句
2. 三列指标卡  
   - 核心茶类  
   - 业务闭环  
   - 运营目标
3. 茶文化说明区  
   - 茶文化背景 + 系统价值描述

## 4. Logo 设计规范

- 文件：`RuoYi-WMS-VUE/src/assets/logo/tea-logo.svg`
- 设计元素：
  - 外环：茶绿渐变，代表品牌稳健；
  - 叶片：主视觉核心，表达茶叶文化；
  - 中轴与圆点：强调秩序和中台能力。
- 适配：
  - SVG 可缩放；
  - 适配浅色背景；
  - 可复用于侧边栏与导航栏。

## 5. 品牌替换点

- 左上侧边栏品牌：Logo + `国茶经营管理`
- 顶部右侧文案区：替换为 Logo + `国茶经营管理系统`
- 默认首页标题：`茶文化首页`
