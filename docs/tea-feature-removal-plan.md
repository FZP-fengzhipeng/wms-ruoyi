# 茶叶系统功能裁剪方案

## 1. 目标

- 移除以下功能并避免死链：
  - 茶业驾驶舱
  - 茶业经营大屏
  - 业务蓝图
  - 茶仓盘点
- 同步清理数据库菜单/权限与后端盘点接口暴露。
- 保持 `茶企档案`、`采购入仓`、`销售出仓`、`加工调拨`、`库存分析` 正常可用。

## 2. 裁剪范围

### 2.1 前端

- 路由裁剪：移除 `dashboard/description` 入口，首页改为茶文化首页。
- 页面裁剪：删除顶部三项历史页面与茶仓盘点页面/API调用。
- 品牌替换：替换左上角品牌标识与顶部右侧文案。

### 2.2 后端

- 下线盘点模块 Controller 路由，避免继续暴露 `/wms/checkOrder*`。

### 2.3 数据库

- 删除茶仓盘点菜单与角色权限绑定。
- 删除盘点状态字典。
- 清理盘点业务演示数据与盘点流水。

## 3. 风险与控制

- 风险：直接删除菜单可能导致角色存在残留权限引用。
  - 控制：先删 `sys_role_menu` 再删 `sys_menu`。
- 风险：盘点字典删除后，仍有历史盘点流水时展示值不完整。
  - 控制：同步清理 `order_type=4` 的库存流水演示数据。
- 风险：前端路由改动造成 404。
  - 控制：路由清理后执行前端生产构建验证。

## 4. 回退建议

- 执行前备份 `ry_tea`。
- 若需回退：
  - 使用备份恢复数据库；
  - 恢复 Git 变更到裁剪前版本。
